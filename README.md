# Student Career Database

## Overview

The **Student Career Database** is a MySQL database designed to store and manage student academic and career-related information. It includes a structured schema, sample data, and a collection of SQL queries that demonstrate essential database operations and data analysis techniques. The database supports efficient retrieval of information related to academic performance, career interests, skills, internships, certifications, and placement status. 


## Features

- Structured relational database design
- Student career and academic records
- Sample dataset containing 100 records
- SQL queries for data retrieval and analysis
- Data filtering, sorting, and aggregation
- Department-wise and career-wise analysis
